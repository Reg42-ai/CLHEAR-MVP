# Licences

CLHEAR is licensed by artefact, not by repository, so that banks and vendors can embed the outputs without copyleft concerns and the standard itself stays freely quotable.

| Artefact | Licence | SPDX | Text |
|---|---|---|---|
| Standard text, schemas, governance documents, release notes, roadmap | Creative Commons Attribution 4.0 International | `CC-BY-4.0` | `CC-BY-4.0.txt` |
| Open data outputs: L2–L6 agnostic records, L7 base priorities, vault packs, snapshots | Open Data Commons Attribution License 1.0 | `ODC-By-1.0` | `ODC-By-1.0.txt` |
| Evals harness, SDKs, reference tooling | Apache License 2.0 | `Apache-2.0` | `Apache-2.0.txt` |

Attribution for data outputs: "Contains CLHEAR data © Reg42 and contributors, licensed under ODC-By 1.0 — https://clhear.org". A release identifier (`YYYY.MM.DD`) satisfies the version notice.

## Trademark

"CLHEAR" and the CLHEAR marks are held by Reg42. The licences above do not grant trademark rights; see `../governance/TRADEMARK_POLICY.md`. Conformance marks (CL1–CL4) are granted only through the conformance program.

## Patent

Reg42's patent application covering the CLHEAR derivation method (filed 11 September 2026) is licensed royalty-free for agnostic-mode use under the patent grant in the Contributor License Agreement (`../governance/CLA.md`, §3). Commercial re-derivation engines are outside that grant.

## Source texts

Instruments in the L1 corpus keep their publishers' terms. The rights basis per source (`public_domain`, `open_licence`, `licensed`, `byol_only`, `derived_only`) is recorded on the record and decides whether verbatim text appears in any output (invariant I8). Nothing in this repository republishes text whose basis does not allow it.
