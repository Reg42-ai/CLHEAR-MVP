# Evidence template — Process / Workflow

Shows that a procedure operates as the blueprint item requires.

| Field | Content |
|---|---|
| Reference | procedure id; or the system and report that records executions |
| Obligations | `OBL-` ids or the `ITM-` id |
| Trigger | what starts the procedure (event, schedule) — compare with characteristic `trigger` |
| Performer | role — compare with `performing_role` |
| Cadence | how often — compare with `cadence` |
| Output and record | what is produced and where it is kept — compare with `output`, `record` |
| Period | the period the records cover |

Operating evidence over a period: a sample of execution records with dates spread across the period; exceptions and how they were handled.
