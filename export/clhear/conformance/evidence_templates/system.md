# Evidence template — System / Configuration

Shows that a control system is in place and configured as required.

| Field | Content |
|---|---|
| Reference | system name and configuration export hash |
| Obligations | `OBL-` ids or the `ITM-` id |
| Configuration | the parameters the characteristics name (thresholds, lists, rules) with their values — compare with the blueprint |
| Change control | how configuration changes are approved and logged |
| Monitoring | how the system's operation is monitored; alert routing |

Operating evidence over a period: configuration change log; alert or output volumes over the period; a sample of outputs handled.
