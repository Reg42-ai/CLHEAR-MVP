# Evidence template — Document (policy, standard, charter)

Shows that a required document exists, is approved, current and owned.

| Field | Content |
|---|---|
| Reference | document id or SHA-256 |
| Title and version | as approved |
| Obligations | `OBL-` ids the document addresses, or the `ITM-` id |
| Owner | accountable role |
| Approver and approval date | body or role; date |
| Review cadence | as stated in the document; compare with the blueprint characteristic `review_cycle` and record any deviation |
| Last review date | must fall within one cadence of today |
| Distribution | where staff find it (system, path) |

Operating evidence over a period: approval minutes; version history showing reviews at the stated cadence.
